# Utrecht on the Move / Utrecht in beweging

A static, bilingual (Dutch/English) interactive map story about traffic projects in Utrecht, Netherlands. Utrecht gives priority to walking, cycling and public transport, and creates more room for greenery, play and spending time outdoors. The map shows a selection of projects (currently mostly cycling) that together form one strategy. See the [official overview of traffic projects](https://www.utrecht.nl/wonen-en-leven/verkeer/verkeersprojecten).

Built with vanilla HTML, CSS and JavaScript, [MapLibre GL JS](https://maplibre.org/) and the [OpenFreeMap](https://openfreemap.org/) Liberty basemap. No build step, no API keys, no server-side code.

**Live site:** https://bertt.github.io/utrecht-cycling-mapstory/

## Bilingual interface

- Dutch (`nl`) is the default; English (`en`) is available via the **NL | EN** switcher in the header.
- The choice is stored in `localStorage` (`utrecht-mapstory-lang`).
- Share a direct English link with `?lang=en` (e.g. `https://bertt.github.io/utrecht-cycling-mapstory/?lang=en`); `?lang=nl` forces Dutch. The parameter overrides the stored choice.
- Switching language updates all visible text, accessibility labels, the `<html lang>` attribute and any open map popup.

## Run locally

The page loads GeoJSON with `fetch`, so serve it over HTTP (opening `index.html` directly will not work):

```bash
python -m http.server 8000
# or: npx serve .
```

Then open <http://localhost:8000>.

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. All asset paths are relative, so the site works under `https://<user>.github.io/<repo>/`.

## Project structure

```
index.html            Page structure
css/style.css         Styling
js/app.js             Map, chapters, cards, popups, language switching
js/translations.js    All Dutch/English strings
data/routes.geojson   Route (LineString) features
data/projects.geojson Parking (Point) and area (Polygon) features
data/redesigns.geojson Approximate points for ~40 utrecht.nl traffic projects (generated by `node tools/build-redesigns.mjs`)
data/doorfietsroutes.geojson Provincial through-routes (F-routes), approximate lines (generated by `node tools/build-doorfietsroutes.mjs`)
tools/snap-routes.mjs Builds routes.geojson from anchor points via the OSM bike router
```

## Data

Both GeoJSON files are merged at load time and share one property model:

```json
{
  "id": "unique-slug",
  "title": { "nl": "…", "en": "…" },
  "category": "hoofdfietsroute | doorfietsroute | herinrichting | fietsenstalling | buurtstalling",
  "status": "in voorbereiding | in uitvoering | gepland | bestaand",
  "major": true,
  "planning": { "nl": "…", "en": "…" },
  "description": { "nl": "…", "en": "…" },
  "goals": "fiets, groen, klimaat, veiligheid, leefbaarheid, overstappen",
  "benefits": { "nl": { "cycling": "…", "green": "…", "safety": "…" }, "en": { … } },
  "connections": { "nl": "…", "en": "…" },
  "url": "https://www.utrecht.nl/…",
  "urlType": "overview"
}
```

- `major` makes the marker pulse and shows the project on the intro chapter.
- `urlType: "overview"` is optional and labels the link as an overview page. It is used where no dedicated project page exists (the Utrecht–Houten F409 route and Utrecht Centraal parking).
- `url` is required, must point to utrecht.nl, and is used in both cards and popups.

### Adding or updating a project

1. Add a feature to `routes.geojson` (LineString) or `projects.geojson` (Point/Polygon) with a unique `id`.
2. Provide every property above in both languages.
3. Every project is listed automatically as a card and a labelled marker; no extra configuration is needed.
4. Use `[longitude, latitude]` coordinate order.

### Data sources and attribution

- Project descriptions summarise the official project pages on [utrecht.nl](https://www.utrecht.nl/); each feature links to its page. Statuses were taken from those pages when written and must be re-checked.
- Basemap: [OpenFreeMap](https://openfreemap.org/) tiles, © [OpenMapTiles](https://openmaptiles.org/), data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
- Map library: MapLibre GL JS (BSD-3-Clause).

> **Important:** project coordinates and area outlines are **approximate hand-drawn starting points**, not official project boundaries. Check them, and replace them with verified municipal or OpenStreetMap data, before publication. No exact construction dates are given; see each project page for the current schedule.

## Editing translations

All user-facing text is in `js/translations.js` under the `nl` and `en` keys. Keep both structures identical. Static HTML uses `data-i18n="key.path"` for text and `data-i18n-aria="key.path"` for `aria-label`s. Chapter text lives in `chapters[]`, in the same order as `CHAPTERS` in `js/app.js` (which defines camera positions, focus projects and highlight colours).
